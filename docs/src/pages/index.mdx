## What's inside

- **Primitives**: buttons, inputs, switches, pills, metrics, progress bars, sparklines, panels and
  decorative HUD layers such as corner brackets, scanlines and light traces.
- **Compositions**: navigation lists, tabs, tables, code blocks, callouts, a HUD shell, a status
  dock and the `WindowManager`.
- **Window system**: draggable, resizable windows on a 9-slot snap grid, with the hooks to build
  your own.
- **Orbs**: `CssOrb` with five states in the main entry, `ThreeOrb` in `jarvis-react-ui/orb`.
- **Sound**: an audio engine and React hooks that give every interactive component hover and click
  sounds.

Start with [Installation](/getting-started/installation), then build your first screen in
[Usage](/getting-started/usage).

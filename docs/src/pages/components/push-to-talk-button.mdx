# PushToTalkButton

<Lead>
    The round microphone button of the voice HUD. It toggles the mic and, while `active`, shows two
    pulsing rings and a stronger glow so the user can see that JARVIS is listening.
</Lead>

<ComponentMeta component="PushToTalkButton" />

## Toggle the microphone

The button is fully controlled: keep the mic state yourself, pass it as `active` and flip it in
`onClick`. `onClick` is a normal button click handler and receives the click event; a handler
without arguments such as `() => setLive((v) => !v)` works too. A dashed rim rotates slowly in both
states.

## Hold to talk

All native `<button>` attributes and events are forwarded, including `disabled`, `id`, `ref` and
the pointer and keyboard events. For walkie-talkie style input, turn the mic on in `onPointerDown`
and off in `onPointerUp`; also stop on `onPointerLeave` and `onPointerCancel` so the mic does not
stay live when the pointer slides off or the browser cancels the gesture. `onKeyDown`/`onKeyUp` for
Space give keyboard users the same hold behavior (ignore `e.repeat` while the key is held).

## Custom content

`children` replace the default `Mic` icon. Mark the icon `aria-hidden` and describe the action with
`aria-label`, because the button has no visible text.

<Callout variant="warning" title="ariaLabel is deprecated">
    The `ariaLabel` prop still works but is deprecated. Use the standard `aria-label` attribute
    instead; when both are set, `aria-label` wins.
</Callout>

## With the orb state

In an assistant UI the button usually drives the orb state (`AppOrbState`) rather than a plain
boolean. Here a click moves `idle` to `listening`, a second click ends the turn (`thinking`), and the
reply plays out as `speaking` before returning to `idle`. A [WaveformMeter](/components/waveform-meter)
on each side runs while audio flows, and a [StatusLabel](/components/status-label) names the state.

<Demo name="push-to-talk-button/VoiceLoop" />

For a global keyboard shortcut (for example Space anywhere on the page), listen for
`keydown`/`keyup` in your app and update `active` yourself; a [Hint](/components/hint) can advertise
the key.

## Sound

Hovering plays `hover_button` and clicking plays `click` through the nearest `SfxProvider`. Without a
provider the button stays silent. Pointer and key handlers you pass do not play extra sounds. See
[Sound effects](/getting-started/sound).

## Accessibility

- Renders a native `<button type="button">`, so it is focusable and Enter and Space activate it.
  `disabled` disables it and dims it.
- `aria-label` (default `Push to talk`) is the accessible name; the icon is decorative. The
  deprecated `ariaLabel` prop is used only when `aria-label` is not set.
- `aria-pressed` mirrors `active`, so screen readers announce it as a toggle button that is pressed
  while the mic is live. Pass `aria-pressed` yourself to override it.
- The focus ring (2px accent outline) is visible on keyboard focus only (`focus-visible`).

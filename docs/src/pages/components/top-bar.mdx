# TopBar

<Lead>
    The TopBar is the status strip at the top of the HUD. It has three slots, left, center and
    right, and carries the panel chrome: corner brackets and a light trace that circles its border.
</Lead>

<ComponentMeta component="TopBar" />

## Positions

`position` decides how the bar is placed:

| Value    | Behavior                                                                                       |
| -------- | ---------------------------------------------------------------------------------------------- |
| `fixed`  | Default. Pinned to the viewport, 10px from the top, left and right edges, above other content. |
| `sticky` | Full width in the document flow; sticks 10px below the top of its scroll container.            |
| `static` | Full width in the document flow, like a normal block, e.g. inside a page header or a card.     |

The bar is always 40px high. With `fixed`, leave room at the top of your layout: the slot grid of
[WindowManager](/components/window-manager) reserves the top 60px for it.

## Slots

Each slot takes any React node. Use the left slot for time or status text, the center for a title

## Fixed

The default. In this demo the bar is pinned to the demo frame, because the frame creates a
containing block; in an app it is pinned to the viewport.

## Accessibility

- The TopBar renders plain `<div>` elements without a landmark role. If it acts as the page header,
  wrap it in a `<header>` element.
- Keep interactive content in the slots keyboard accessible, e.g. `Button`, or `IconButton` with a
  `label`.

# GlassCard

<Lead>
    GlassCard is a [Panel](/components/panel) framed by an extra set of
    [CornerBrackets](/components/corner-brackets). Use it for standalone dashboard tiles that should
    stand out a little more than a plain panel.
</Lead>

<ComponentMeta component="GlassCard" />

## Basic

The outer bracket wrapper is an `inline-block` and takes the size of the panel inside it. Size the
panel through `bodyClassName`; `className` goes to the wrapper and suits margins or positioning.

<Demo name="glass-card/Basic" />

## Focus

`focused` is passed to both parts: the brackets brighten to the bright accent and the panel switches
to its focused look with an accent border and an animated bloom. GlassCard does not track focus
itself, so keep the focused card in state.

<Demo name="glass-card/Focused" />

## Dashboard tiles

GlassCard takes any content. Combine it with [Metric](/components/metric) and
[StatusBadge](/components/status-badge) for compact status tiles. For header actions, an index glyph
or a badge, use a [Panel](/components/panel) directly; GlassCard only forwards `title`.

<Demo name="glass-card/Dashboard" />

## Sound

Hovering the card plays `hover_panel` through the nearest `SfxProvider`, like every Panel. Without a
provider it stays silent. See [Sound effects](/getting-started/sound).

## Accessibility

- GlassCard renders presentational `<div>`s without a landmark role; the brackets are
  `aria-hidden`. Wrap it in a `<section>` with an `aria-label` when it is a distinct region.
- `focused` is purely visual and does not move keyboard focus.

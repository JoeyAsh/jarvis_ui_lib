# GlassCard

<Lead>
    GlassCard is a [Panel](/components/panel) in an `inline-block` wrapper, framed by the panel's
    own corner brackets. Use it for standalone dashboard tiles that size themselves to their
    content.
</Lead>

<ComponentMeta component="GlassCard" />

## Basic

The outer wrapper is an `inline-block` and takes the size of the panel inside it. Size the panel
through `bodyClassName`; `className` goes to the wrapper and suits margins or positioning. Only
one set of corner brackets is drawn: the panel's own, which lengthen on hover.

<Demo name="glass-card/Basic" />

## Focus

`focused` switches the panel to its focused look: longer corner brackets in the bright accent, an
accent border and an animated bloom. GlassCard does not track focus itself, so keep the focused card
in state.

<Demo name="glass-card/Focused" />

## Dashboard tiles

GlassCard takes any content. Combine it with [Metric](/components/metric) and
[StatusBadge](/components/status-badge) for compact status tiles. For header actions, an index glyph
or a badge, use a [Panel](/components/panel) directly; GlassCard only forwards `title`.

<Demo name="glass-card/Dashboard" />

## Sound

Hovering the card plays `hover_panel` through the nearest `SfxProvider`, like every Panel. Without a
provider it stays silent. See [Sound effects](/getting-started/sound).

## Accessibility

- GlassCard renders presentational `<div>`s without a landmark role; the brackets are decorative
  empty elements. Wrap it in a `<section>` with an `aria-label` when it is a distinct region.
- `focused` is purely visual and does not move keyboard focus.

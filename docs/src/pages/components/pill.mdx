# Pill

<Lead>
    A small uppercase tag with a hairline border. Use it to show the state of a system, a connection
    or a task at a glance.
</Lead>

<ComponentMeta component="Pill" />

## Variants

`default` is neutral. `ok`, `warn` and `err` map to the success, warning and error colors, and
`info` uses the bright accent for transient states such as syncing.

## Accessibility

- Renders a plain `<span>`; it has no role and is not focusable. Native attributes (`id`, `title`,
  `aria-*`, `data-*`) are forwarded to it.
- The text is the only status information for screen readers. Do not rely on color alone: the word
  inside the pill must name the state.
- For a status that changes live and must be announced, set `aria-live="polite"` on the pill or
  wrap the readout in an element with it.

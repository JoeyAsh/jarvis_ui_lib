# StatusBadge

<Lead>
    A small connection indicator: a colored dot followed by an uppercase label. Put it in a
    [TopBar](/components/top-bar) or a panel header to show whether a link or service is up.
</Lead>

<ComponentMeta component="StatusBadge" />

## States

`state` sets the dot color. The label is free text; without one the badge reads `LINK · SECURE`.

| `state`   | Dot color  |
| --------- | ---------- |
| `online`  | green      |
| `warn`    | amber      |
| `offline` | muted gray |

<Demo name="status-badge/States" />

## Pulse

While `state` is `online`, the dot pulses by default: it fades and shrinks slightly about once a
second. Set `pulse={false}` for a steady dot. `warn` and `offline` never pulse.

## Accessibility

- The badge is plain text in a `<span>`. The state is only conveyed by the dot color, so make the
  `label` say it too (`Link · lost`, not just `Link`).
- It is not a live region, so changes are not announced. If screen reader users need to know when
  the connection drops, also announce it, for example with a [Toast](/components/toast).
- The pulse animation does not respond to `prefers-reduced-motion`; pass `pulse={false}` to turn it
  off.

# CssOrb

<Lead>
    CssOrb is the animated JARVIS orb, built from CSS gradients, rings and a few orbiting particles.
    It shows the assistant's state at a glance and needs no WebGL. For the Three.js particle version
    see [ThreeOrb](/components/three-orb).
</Lead>

## States

`state` takes an `AppOrbState`. CssOrb gives five of them their own look:

| State       | Look                                                                  |
| ----------- | --------------------------------------------------------------------- |
| `idle`      | The blue core floats slowly up and down.                              |
| `listening` | The core breathes, and three pulse rings expand outward from it.      |
| `thinking`  | The core's color slowly shifts in hue and saturation.                 |
| `speaking`  | The core's glow pulses quickly, like a voice level.                   |
| `working`   | Core, rings, ticks, pulses and particles turn amber; the glow pulses. |

`follow_up`, the sixth `AppOrbState` value, has no style of its own and looks like `idle`. The demo
cycles through the five styled states every three seconds.

The states come from a voice assistant, but they work for any app: use `idle` when nothing happens,
`listening` while waiting for or receiving input, `thinking` while computing an answer, `speaking`
while presenting a result and `working` for background tasks (a scan, a sync, a tool run).

## Rings and particles

`rings` draws five concentric rings (360 to 920px wide) and a rotating tick ring around the core.
`particles` adds six dots orbiting at a radius of 180 to 330px. Both are on by default; turn them off for a
quieter orb or a small container. Pick a state with the
[StateSimulator](/components/state-simulator) to compare.

## Sizing

The root element is a zero-size anchor centred (`left: 50%; top: 50%`) in its nearest positioned
ancestor. The orb has no size prop; its parts have fixed sizes:

| Part                | Diameter     |
| ------------------- | ------------ |
| Core                | 280px        |
| Particles           | 360 to 660px |
| Rings and tick ring | 360 to 920px |

Place the orb in a `position: relative` container with a fixed height, and add `overflow: hidden`
when it should not spill over the surrounding layout. As a rule of thumb:

- Full orb: a container of about 920 × 920px, or a full-screen background where the outer rings may
  be cut off.
- Smaller boxes (300 to 700px): turn `rings` off and, below about 660px, `particles` too. The core
  needs at least 300 × 300px.

```tsx
<div style={{ position: 'relative', height: 360, overflow: 'hidden' }}>
    <CssOrb state="idle" rings={false} particles={false} />
</div>
```

## Accessibility

- By default the orb is decorative: the root is `aria-hidden="true"`, so assistive technology
  skips it. Show the state as text as well, for example with a
  [StatusLabel](/components/status-label).
- Pass `aria-label` when the orb itself should be announced. The root then gets `role="img"` and
  that label, and is no longer hidden:

```tsx
<CssOrb state={state} aria-label={`Assistant ${state}`} />
```

- With `prefers-reduced-motion: reduce`, the CSS animations of the core, rings and pulses stop, and
  the particles' `requestAnimationFrame` loop does not run: they stay parked at their start
  positions. CssOrb follows changes of the preference while it is mounted.
